**Object-oriented programming (OOP)** is a software design model centered on classes and objects rather than functions and logic. Key pillars include encapsulation, inheritance, and polymorphism.

## 1. Encapsulation

- **Definition:** Bundling data (variables) and methods into a single unit (a class) while restricting direct access to the internal state using access modifiers (e.g., `private`).
- **Key Phrase:** *"Data protection and controlled access."*
- **Analogy:** A **capsule/pill**—you consume the medicine without interacting with the raw powder inside.

## 2. Abstraction

- **Definition:** Hiding complex underlying implementation details and showing only the essential interfaces to the user.
- **Key Phrase:** *"Showing WHAT it does, hiding HOW it works."*
- **Analogy:** A **car accelerator pedal**—you press it to speed up, without needing to understand the engine's internal combustion process.

## 3. Inheritance

- **Definition:** The mechanism by which a child class acquires the properties and behaviors of a parent class to promote code reusability and logical hierarchy.
- **Key Phrase:** *"Code reuse and class hierarchy."*
- **Analogy:** **Genetics**—a child inherits physical traits (like eye color) from their parent class while adding their own unique traits.

## 4. Polymorphism

- **Definition:** The ability of different objects to respond to the same method call in their own specific way (*"many forms"*). It occurs via **Overloading** (compile-time) or **Overriding** (runtime).
- **Key Phrase:** *"One interface, multiple behaviors."*
- **Analogy:** A **power button**—pressing it turns on a phone, a laptop, or a TV, but each device performs a completely different boot process.

## ⚡ Quick Comparison Cheat Sheet

| Pillar | Core Purpose | Keyword |
| --- | --- | --- |
| **Encapsulation** | Protect internal state | *Security / Control* |
| **Abstraction** | Hide unnecessary detail | *Simplification* |
| **Inheritance** | Share common behavior | *Reusability* |
| **Polymorphism** | Allow flexible implementations | *Flexibility* |
